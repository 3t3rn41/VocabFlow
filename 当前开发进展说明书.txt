一、项目概述
===============================================================================

VocabFlow 是一个词汇与句子学习应用，前端使用 React + TypeScript，后端使用
Express + MySQL 提供用户认证、SRS 同步、TTS 代理、ASR 语音识别等服务。

核心功能：
  1. 单词学习（SRS 间隔重复算法，支持多词书）
  2. 单词听写模式（听音频拼写单词，SRS 评分）
  3. 句子拼写练习（中译英，逐词输入，下划线占位）
  4. 句子 SRS 集成（FSRS 调度，到期句子智能复习）
  5. 语音识别与发音评分（ASR + 逐词对比）
  6. 学习提醒功能（浏览器通知 + 定时提醒）
  7. 学习统计与进度跟踪
  8. 多词书选择（中考 / 高考 / CET4 / CET6 / 雅思词汇 / 雅思对话 / 语感练习）

二、技术栈
===============================================================================

【前端】
  - 框架：React 19 + TypeScript
  - 构建工具：Vite 8
  - 样式：Tailwind CSS 3 + 自定义 CSS 动画
  - 状态管理：Zustand 5
  - 路由：react-router-dom 7
  - 图表：Recharts 3
  - TTS：本地缓存音频 (WAV) + 浏览器 Speech Synthesis + mimo TTS (后端代理)
  - ASR：Web Speech API + 服务端 Whisper 推理 (@huggingface/transformers)
  - 音频播放：Web Audio API (AudioBufferSourceNode) + HTMLAudioElement 回退

【后端】
  - 框架：Express 4 + TypeScript (tsx 运行)
  - 数据库：MySQL 2 (mysql2)
  - 认证：JWT (jsonwebtoken) + bcryptjs
  - SRS：ts-fsrs 5 (FSRS-4.5)
  - ASR：@huggingface/transformers (Whisper 模型，服务端推理)
  - TTS 代理：转发至 mimo TTS API

三、数据来源
===============================================================================

【词书数据 (src/data/wordbooks/)】
  1. zhongkao_words.json          — 中考核心词汇（1672 词）
     格式：{ "word": "中文释义" }

  2. gaokao_words.json            — 高考核心词汇（3429 词）
     格式：{ "word": "中文释义" }

  3. CET4_words.json              — 大学英语四级词汇（3465 词）
     格式：{ "word": "中文释义" }

  4. CET6_words.json              — 大学英语六级词汇（1761 词）
     格式：{ "word": "中文释义" }

  5. IELTS_words.json             — 雅思核心词汇（605 词）
     格式：含音标、词性、中文释义、英文例句、中文例句翻译

  6. IELTS_sentences.json         — 雅思日常对话（6 个 Band，711 句）
     格式：按 Band > Topic > Dialogue 层级组织，每句含中文和英文

  7. language_sense_sentences.json — 英语语感分级练习（3 个级别，600 句）
     格式：按 Level > Topic > Dialogue 层级组织（初中篇/高中篇/大学篇）

【本地音频缓存 (public/audio/)】
  - word/     — 单词发音 WAV 文件（按词书分类）
  - sentence/ — 句子发音 WAV 文件（按词书和级别分类）
  - manifest.json — 文本到音频文件的映射表

六、关键设计决策
===============================================================================

1. 前后端分离架构
   - 前端 React + Vite，后端 Express + MySQL
   - 用户数据存储在 MySQL，通过 JWT 认证
   - 词书数据为本地 JSON 文件，通过 Vite 导入加载
   - 支持离线使用本地音频缓存

2. TTS 三级播放优先级
   - 优先使用本地缓存音频 (public/audio/ 下的 WAV 文件)
   - 回退到浏览器内置 SpeechSynthesis API
   - 最终回退到 mimo TTS 在线服务（通过后端代理避免 CORS）
   - 全局播放取消机制确保不会多个声音叠加

3. 音频预加载与 Web Audio API
   - 句子加载时立即 fetch + decodeAudioData 预解码为 AudioBuffer
   - 完成句子后通过 AudioBufferSourceNode.start(0) 直接播放
   - AudioBuffer 已完全解码在内存中，从第一个样本开始播放，零延迟零截断
   - HTMLAudioElement 作为回退方案（canplaythrough + canplay 双事件保障）

4. 双层 ASR 策略
   - Tier 1: Web Speech API（Chrome/Edge/Safari 原生支持，实时中间结果）
   - Tier 2: 服务端 Whisper 推理（通过后端 /api/asr 端点，支持所有浏览器）
   - 自动检测最佳方案，确保所有设备/浏览器均可使用语音识别
   - 服务端使用 ScriptProcessorNode 录音 → WAV 编码 → Whisper 推理

5. 句子拼写输入模型
   - 采用"逐词输入"而非"整句输入"
   - 每个单词对应一个下划线词槽，标点符号直接显示
   - 输入正确自动跳转，Backspace 退回上一词
   - 隐藏 input 捕获键盘输入，可视化层展示词槽状态
   - 颜色反馈：正确绿色、错误红色、当前输入蓝色边框

6. 熟知跳过机制
   - 未勾选"复习全部"时，进入话题自动跳到第一个未熟知句子
   - 翻页时自动跳过熟知句子
   - 全部熟知时提示并阻止进入话题
   - 熟练度 ≥85 自动标记熟知

7. SRS 引擎
   - 使用 ts-fsrs (FSRS-4.5) 算法，比传统 SM-2 更精准
   - 前后端均使用相同算法，确保数据一致
   - 保留率可配置
   - 句子 SRS 集成：复用 srs_cards 表，wordId 使用复合格式
     srs-sentence:${band}:${topicIdx}:${dialogueIdx}
   - 熟练度 → Grade 映射：≥85→Easy, ≥65→Good, ≥40→Hard, <40→Again
   - 到期句子出现在复习队列中，支持 SRS 复习模式

8. 单词听写模式
   - 听音频拼写单词的独立练习模式 (/dictation)
   - 自动播放音频，输入拼写，即时正误反馈
   - 提示功能（逐字母揭示）和看答案功能
   - 评分后通过 SRS 持久化，与单词复习共享进度
   - 统计：正确数、连击数、正确率

9. 学习提醒功能
   - 浏览器 Notification API 通知
   - 可配置提醒时间（默认 20:00）
   - 检查当天是否已学习（单词复习日志 / 句子练习记录）
   - 每日只提醒一次，localStorage 记录上次提醒日期
   - 设置存储在 localStorage（不同步到后端）

10. 动画系统
    - 卡片滑入过渡（animate-cardSlideIn）
    - 交错列表项渐入（animate-stagger + animationDelay）
    - 空状态弹跳（animate-emptyBounce）
    - 数字翻滚渐入（animate-numberPop）
    - 进度条微光效果（shimmer-bar）
    - 卡片悬停抬升（card-hover-lift）
    - 淡入缩放（animate-fadeInScale）
    - Toast 弹入（animate-toastIn）
    - 心跳脉冲（animate-heartBeat）

八、已知限制
===============================================================================

1. TTS 发音的本地音频缓存覆盖范围有限，未覆盖的文本回退到
   浏览器 SpeechSynthesis 或 mimo TTS，音质可能不一致。

2. 服务端 ASR (Whisper) 需要后端服务运行，首次加载模型需要下载
   （约 40MB），后续从缓存加载。

3. SRS 复习队列在词书切换时不会自动迁移（切换词书后从新词开始）。

4. 词库搜索仅在当前词书范围内进行，不支持跨词书搜索。
