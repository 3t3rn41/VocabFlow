一、项目概述
===============================================================================

VocabFlow 是一个纯本地化的词汇与句子学习应用，所有数据存储在浏览器本地
（IndexedDB + localStorage），不依赖任何外部 API（TTS 使用浏览器内置
Speech Synthesis 引擎）。

核心功能：
  1. 单词学习（SRS 间隔重复算法）
  2. 句子拼写练习（中译英，逐词输入，下划线占位）
  3. 学习统计与进度跟踪
  4. 多词书选择（高考词汇 / 雅思词汇 / 雅思日常对话）

===============================================================================
二、技术栈
===============================================================================

  - 前端框架：React 18 + TypeScript
  - 构建工具：Vite
  - 样式：Tailwind CSS + 自定义 CSS 动画
  - 状态管理：Zustand
  - 本地存储：idb-keyval (IndexedDB)
  - SRS 算法：ts-fsrs (FSRS-4.5)
  - 路由：react-router-dom
  - 图表：Recharts
  - TTS：浏览器 Speech Synthesis API

===============================================================================
三、数据来源
===============================================================================

  1. gaokao_words.json     — 高考核心词汇（3429 词）
     格式：{ "word": "中文释义" }

  2. IELTS_words.json      — 雅思核心词汇（605 词）
     格式：含音标、词性、中文释义、英文例句、中文例句翻译

  3. IELTS_sentences.json  — 雅思日常对话（6 个 Band，710 句）
     格式：按 Band > Topic > Dialogue 层级组织，每句含中文和英文

六、关键设计决策
===============================================================================

1. 纯本地化架构
   - 移除了所有外部 API 依赖（原 Maimemo API、TTS API）
   - 数据来源为本地 JSON 文件，通过 Vite 原生 JSON 导入加载
   - 存储层从 sql.js (WASM) 迁移到 idb-keyval (IndexedDB)
   - 优势：离线可用、无网络延迟、无隐私顾虑

2. 句子拼写输入模型
   - 采用"逐词输入"而非"整句输入"
   - 每个单词对应一个下划线词槽，标点符号直接显示
   - 输入正确自动跳转，Backspace 退回上一词
   - 隐藏 input 捕获键盘输入，可视化层展示词槽状态
   - 颜色反馈：正确绿色、错误红色、当前输入蓝色边框

3. SRS 引擎
   - 使用 ts-fsrs (FSRS-4.5) 算法，比传统 SM-2 更精准
   - 卡片状态和复习日志存储在 IndexedDB
   - 支持撤销操作
   - 保留率可配置

4. 进度持久化
   - 句子完成进度：Record<"band:topicIdx", number[]>
   - 句子练习位置：{ band, topicIdx, dialogueIdx }
   - 均存储在 IndexedDB，刷新后自动恢复

八、已知限制
===============================================================================

1. TTS 发音依赖浏览器 Speech Synthesis API，不同浏览器/系统的语音质量
   和可用语音列表可能不同。

2. 句子练习数据仅包含雅思日常对话，暂不支持自定义句子数据。

3. SRS 复习队列在词书切换时不会自动迁移（切换词书后从新词开始）。

4. 词库搜索仅在当前词书范围内进行，不支持跨词书搜索。

5. 统计图表（近30天复习量）已移除独立页面，核心数据整合到学习页。
   如需详细图表，可考虑恢复独立统计页。
